# Hypersubjectivity

Hypersubjectivity asks when a **subject's actual situated perspective** relates hyperobjects and realities, and what further mechanism would make that linkage a source of genuine novelty. Tyler proposed this as a separate field alongside Hyperobjectivity while developing a reality–consciousness–hyperemergence account.

This is a **[FRAME] research candidate**—an explicit construction with unresolved obligations—not a definition of consciousness, a native derivation, or an empirical finding. The [finite executable witness](hypersubjectivity.py) rejects cheap links made from subjectifiability alone, two different subjects, or an unnamed mechanism. Its `PASS` concerns typed local records only; consciousness and cross-reality transport remain `UNKNOWN`. Read [FIELD_SPEC.md](FIELD_SPEC.md) for the field boundary, [PROVENANCE.md](PROVENANCE.md) for source limits, and [TECHNICAL_DEBT.md](TECHNICAL_DEBT.md) for proof obligations.

Hyperobjectivity owns candidate object instantiation and invariance; this field owns actual perspective and subject-mediated linkage. Hyperethics retains its own entity, mind, consciousness, and normative commitments. A link in this repository cannot borrow any of those conclusions by name.

Run the full local suite with Python 3.10 or later:

```text
python -u -m unittest discover -s tests -v
```

The suite uses only the standard library and prints each named test. Standard-library `unittest` has no per-test process isolation or automatic hung-test stack dump. No physical unit is assigned to subject, perspective, object, or reality-kind identifiers.
